# 画面標準・デザインシステム設計書

## 1. 全体レイアウト構成 (Layout Structure)

一般的な企業サイトのようなフッターは設けず、管理ポータル・Webアプリに特化した**サイドバー ＋ トップヘッダー ＋ メインボディ**のモダンな3エリア構成とします。

```text
+-------------------------------------------------------------------+
| Top Header (ロゴ / アプリ名 / 検索・通知・設定等)                 |
+---------------+---------------------------------------------------+
| Sidebar       | Main Content (Body)                               |
| (開閉式)      |  +----------------------------------------------+ |
|               |  | Page Header (画面タイトル / パンくずリスト)   | |
| - スマブラ    |  +----------------------------------------------+ |
| - 設定        |  | Content Area (機能コンテンツ / 操作パネル)    | |
| - (将来機能)  |  |                                              | |
|               |  |                                              | |
|               |  |                        [右下: アクション]    | |
|               |  +----------------------------------------------+ |
+---------------+---------------------------------------------------+
```

## 2. エリア別詳細・デザイン方針

### 2.1 各エリアの詳細
1. **トップヘッダー:**
   * ポータルロゴ・アプリ名 (`teru-portal`)、サイドバー開閉トグルボタン、右側機能エリア（ダークモード切替など）。
2. **サイドバー:**
   * アイコン＋ラベルの通常表示とアイコンのみの折りたたみ表示を切り替え可能。
   * 機能（スキーマ）ごとにメニューをグループ化。将来的なツール追加に対応できる柔軟な設計。
3. **メインボディ:**
   * **上部:** 画面タイトルおよび概要。
   * **タイトルの直下:** 画面全体レベルのエラー・警告・成功通知アラート（通信エラー、保存完了通知等）。
   * **中央:** ファイター選択、検索フォーム、対策メモ表示領域。
   * **右下:** 頻繁に使用するアクションボタンを配置。
4. **フッター:**
   * **非表示（作成しない）。**

### 2.2 エラー・通知表示ルール
* **デザインスタイル:** 
  * 左端に太いアクセントラインが入ったコールアウト風デザイン（Markdownのブロック引用スタイルを拡張）。
  * 左側にステータスに応じたアイコン（青の !、赤の ⚠、緑の ✓）を配置。
* **表示種類とカラー定義:**
  * **情報 (Info):** 青系 (`bg-blue-950/40 border-l-4 border-blue-500 text-blue-200`) ＋ 青アイコン
  * **エラー (Error):** 赤系 (`bg-red-950/40 border-l-4 border-red-500 text-red-200`) ＋ 赤アイコン
  * **成功 (Success):** 緑系 (`bg-emerald-950/40 border-l-4 border-emerald-500 text-emerald-200`) ＋ 緑アイコン
* **配置ルール:**
  * **画面全体/システムレベル:** 画面タイトル（Page Header）の**直下**に横幅いっぱいで配置。
  * **フォーム/入力レベル:** 該当する入力インプット欄の直下に赤字テキストで表示。

### 2.3 デザイン・カラー方針
* **スタイル:** モダン・ダークモードベース (`bg-slate-900` / `bg-slate-950`)
* **カード・パネル:** やや明るいダーク (`bg-slate-800` / `border-slate-700`)
* **アクセント:** インディゴ〜ブルー系 (`bg-indigo-600` / `hover:bg-indigo-500`)
* **テキスト:** ホワイト〜ライトグレー (`text-slate-100` / `text-slate-400`)
* **ステータスカラー:**
  * **エラー (Error):** レッド系 (`bg-red-900/50` / `text-red-200` / `border-red-700`)
  * **成功 (Success):** グリーン系 (`bg-emerald-900/50` / `text-emerald-200` / `border-emerald-700`)
